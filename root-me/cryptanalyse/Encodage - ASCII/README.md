# Compte Rendu : CTF - Root Me Challenge

## **Challenge : Encodage - ASCII**  
- **Points :** 5  
- **Lien :** Non spécifié dans l'énoncé  

---

## **Objectif**  
Décoder une chaîne encodée en hexadécimal ASCII pour récupérer le flag.

---

## **Étape 1 : Analyse de la chaîne**  
- **Observation :** La chaîne donnée est en hexadécimal ASCII.  
- **Action :** Utiliser un décodeur ASCII pour convertir la chaîne en texte lisible.  

---

## **Étape 2 : Utilisation de l'outil de décodage**  
1. Se rendre sur [dcode.fr/ascii](http://www.dcode.fr/ascii).  
2. Copier la chaîne hexadécimale fournie :  
```
[FLAG CACHÉ]
```
3. La coller dans l'outil de décodage ASCII.

---

## **Étape 3 : Décodage**  
- **Résultat obtenu :**  
```
[FLAG CACHÉ]
```
- **Flag obtenu :**  
```
[FLAG CACHÉ]
```

---

## **Conclusion**  
Ce challenge montre l'importance des conversions entre différentes représentations de données (comme l'hexadécimal vers ASCII) et l'utilisation d'outils pour automatiser ces processus.
